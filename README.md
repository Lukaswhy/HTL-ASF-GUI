# ArchiSteamFarm Python Interface
# HTL ASF GUI

## Overview
This project is a Python-based interface for **ArchiSteamFarm (ASF)**.
It provides a simpler and more user-friendly way to launch and manage ArchiSteamFarm.

The project is designed to be easy to set up, even for beginners.

## Features
- Simple Python interface for ArchiSteamFarm
- Easy configuration using a JSON file
- Beginner-friendly setup

## Requirements
- Python 3.x
- ArchiSteamFarm installed on your system

## Installation & Setup
1. Clone or download this repository.
2. Open the **config** folder.
3. Locate the file **settings.json**.
4. Inside the file, you will see:
   ```json
   {
     "ASF_path": "File location ArchiSteamFarm.exe"
   }
5. change dis "File location ArchiSteamFarm.exe" whit your path |
Example:
{
  "ASF_path": "C:/ArchiSteamFarm/ArchiSteamFarm.exe"
}
